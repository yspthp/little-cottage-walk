# 微光小屋 · 畫裡散步

純靜態網頁，使用指定的小屋照片及原始 GLB，沒有修改來源素材。

## 開啟

在此資料夾啟動任何靜態 HTTP 伺服器，例如安裝 Python 後：

```sh
python -m http.server 8080
```

電腦瀏覽 `http://localhost:8080`。不要直接雙擊 HTML。
手機請使用部署後的 **HTTPS** 網址；一般區域網路 HTTP IP 無法啟用感應器。
部署時需包含 index.html、style.css、app.js、原始 GLB 和背景圖片（保持相對目錄）。
Three.js 0.180.0 從 jsDelivr 載入，需要網絡。

## 操作

- 按「開啟傾斜漫步」，授權並保持舒服的握持姿勢，第一筆有效資料會作為中立姿勢。
- 左右傾斜控制左右，前後傾斜控制草地上的遠近。回到中立姿勢停止。
- 「以現在姿勢校準」可重設中立姿勢；旋轉螢幕後自動重新校準。
- 電腦方向鍵 / WASD，以及手機下方方向按鈕均可操作。
- 人物、陰影、遠近縮放和草地邊界使用同一套圖片座標，畫面縮放不改變活動範圍。

## 素材限制

原始模型約 118 MB，包含約 156 萬頂點，手機第一次載入可能較慢且需要較多記憶體。
模型沒有骨架或動畫，因此目前使用整體轉向、輕微搖擺及起伏模擬漫步，
並非雙腿交替的骨架步行動畫。正式手機發布建議先另製減面、壓縮貼圖及綁骨架版本。
本版不會自動改動原始 GLB。

需要在實際 iOS / Android 的 HTTPS 環境驗證感應器權限與方向。
